
| 종류                      | 용도                                              | 특징                                                                  |
| ------------------------- | ------------------------------------------------- | --------------------------------------------------------------------- |
| `emptyDir`              | 임시 파일·캐시, 같은 Pod의 컨테이너 간 파일 공유 | 컨테이너 재시작에는 유지되지만 Pod 삭제 시 사라짐. 메모리 사용도 가능 |
| `hostPath`              | 노드의 파일·디렉터리 접근                        | 특정 노드에 종속됨. 호스트 접근 권한에 주의                           |
| `configMap`             | 일반 설정 파일 제공                               | ConfigMap의 값을 파일로 마운트                                        |
| `secret`                | 비밀번호·인증서 파일 제공                        | Secret의 값을 파일로 마운트                                           |
| `downwardAPI`           | Pod 자신의 정보 제공                              | Pod 이름·Namespace·라벨 등을 파일로 제공                            |
| `projected`             | 여러 데이터 소스를 한 디렉터리에 제공             | ConfigMap·Secret·ServiceAccount 토큰 등을 조합                      |
| `persistentVolumeClaim` | 영구 저장소 사용                                  | PVC가 연결된 PV를 Pod에 마운트                                        |
| `nfs`                   | 네트워크 공유 저장소 접근                         | 외부 NFS 서버의 디렉터리를 마운트                                     |
| `local`                 | 노드의 로컬 디스크를 PV로 사용                    | 노드 배치 제약을 함께 관리                                            |
| `image`                 | 이미지·OCI 아티팩트의 파일 제공                  | 내용을 읽기 전용으로 마운트                                           |


## hostPath.type

| 타입 | 설명 |
|---|---|
| `Directory` | 해당 경로가 디렉토리여야 함. 없으면 오류 발생. |
| `DirectoryOrCreate` | 디렉토리가 없으면 자동 생성. 있음 → 사용. |
| `File` | 파일이어야 함. 없으면 오류 발생. |
| `FileOrCreate` | 파일이 없으면 빈 파일로 생성. |
| `Socket` | 소켓 파일이어야 함. |
| `CharDevice` | 문자 디바이스여야 함 (예: `/dev/null`). |
| `BlockDevice` | 블록 디바이스여야 함 (예: 디스크). |

**default:** 아무것도 확인하지 않고 마운트 시도  
없으면 그냥 마운트 안됨
