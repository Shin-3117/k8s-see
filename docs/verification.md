검증일: 2026-10-06

| --- | --- |
| `npm run build` | TypeScript·Vite 빌드 통과 |

| `git diff --check` | 공백 오류 없음 |

## 확인한 사용자 결과

- 기본 진입은 전체 구조이며 각 페이지의 hash 주소·제목·목차가 일치한다. 1→8 이동, 뒤로/앞으로, 새로고침을 확인했다.
- 1440·1024·390px에서 모든 페이지의 기본 화면과 상세 도구를 펼친 화면에 문서 가로 넘침이 없다.
- Ingress 재생 중 다른 페이지로 이동하면 재생이 멈춘다. 재방문 시 단계·속도는 유지하고 일시정지 상태다. Pod 내부와 라이프사이클의 상태·리셋은 독립적이다.
- readiness 실패는 Running과 같은 UID를 유지한다. 컨테이너 재시작은 같은 UID에서 restartCount가 증가하며, Pod 교체는 새 UID다. 정상 완료·실패·startup/liveness 실패·반복 재시작·강제 종료 분기를 확인했다.
- Ingress Controller 부재·규칙 불일치·Ready 백엔드 부재와 PVC Delete/Retain을 각각 별도 예시로 확인했다.
- Service 프리셋은 내부 통신 페이지로 연결하며 Pod 생성 과정을 재생하지 않는다.
- 백과사전은 목록으로 열리고 CSI 설명을 선택할 수 있다. Escape로 닫힌다.
- 캔버스 줌·팬·Fit View·노드 드래그와 미니맵을 확인했다. YAML 예시 복사 완료, Apply 재생·일시정지·리셋, 키보드 줄 선택을 확인했다.
- 모바일 목차 열기·페이지 선택, 본문 건너뛰기를 키보드로 확인했다.

브라우저 회귀 검증의 화면과 결과는 `/private/tmp/k8s-learning-check/`에 저장한다. 브라우저 예외는 검증 세션에서 발생하지 않았다.

## 검증 범위와 남은 제약

실제 Kubernetes 클러스터·AWS·Ingress Controller와 연결한 테스트는 수행하지 않았다. 앱은 정해진 데이터로 동작하는 교육용 시뮬레이션이며 로그·etcd 출력도 예시다. EBS/NGINX 예시는 실제 구현과 설정 조건을 설명과 공식 출처로 구분한다.

페이지 진행 상태는 메모리에 보관하며 새로고침하면 초기화한다. 페이지 주소는 유지한다. 빌드에 약 727 kB 번들 크기 경고가 남아 있으며, 배포 성능 최적화는 별도 작업이다.

YAML 복사는 `navigator.clipboard.writeText`가 성공하고 완료 문구를 표시하는 결과를 확인했다. 자동 브라우저의 클립보드 읽기 권한은 허용되지 않아 운영체제 클립보드의 내용을 다시 읽는 검증은 수행하지 않았다.
